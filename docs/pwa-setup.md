# PWA Setup Guide

This document explains how to set up and configure Progressive Web App (PWA) features for PikSend.

## Features

- **Installable**: Users can install PikSend as a standalone app on their devices
- **Offline Support**: Gallery pages and images are cached for offline viewing
- **Push Notifications**: Real-time notifications for comments, favorites, and gallery expiration
- **App-like Experience**: Standalone display mode with custom theme colors

## Configuration

### 1. VAPID Keys for Push Notifications

Push notifications require VAPID (Voluntary Application Server Identification) keys. Generate them once and store in your environment variables.

#### Generate VAPID Keys

Run this script to generate keys:

```typescript
// scripts/generate-vapid-keys.ts
import { generateVapidKeys } from '@/lib/services/push-notification.service';

const keys = generateVapidKeys();
console.log('VAPID Public Key:', keys.publicKey);
console.log('VAPID Private Key:', keys.privateKey);
```

Or use the web-push CLI:

```bash
npx web-push generate-vapid-keys
```

#### Environment Variables

Add these to your `.env` file:

```env
# VAPID keys for push notifications
NEXT_PUBLIC_VAPID_PUBLIC_KEY=your_public_key_here
VAPID_PRIVATE_KEY=your_private_key_here
VAPID_SUBJECT=mailto:contact@piksend.com
```

**Important**: 
- `NEXT_PUBLIC_VAPID_PUBLIC_KEY` must be prefixed with `NEXT_PUBLIC_` to be accessible in the browser
- `VAPID_PRIVATE_KEY` should remain server-side only
- `VAPID_SUBJECT` should be a mailto: or https: URL identifying your application

### 2. Database Migration

Run the push notifications migration:

```bash
npx supabase db push
```

This creates the `push_subscriptions` table for storing user notification subscriptions.

### 3. Manifest Configuration

The PWA manifest is located at `public/manifest.json`. Key configurations:

- **name**: Full application name
- **short_name**: Name shown on home screen
- **theme_color**: Browser UI color (#7c3aed - PikSend purple)
- **background_color**: Splash screen background
- **display**: "standalone" for app-like experience
- **icons**: Multiple sizes for different devices (32x32, 180x180, 192x192, 512x512)

### 4. Service Worker

The service worker is automatically generated by `@ducanh2912/next-pwa` with custom caching strategies:

- **Cloudinary Images**: CacheFirst (7 days)
- **Google Fonts**: CacheFirst (1 year)
- **API Galleries**: NetworkFirst (5 minutes)
- **Gallery Pages**: NetworkFirst (24 hours)
- **Static Assets**: CacheFirst (1 year)

Custom push notification handling is in `public/sw-custom.js`.

## Usage

### For Users

#### Installing the App

1. Visit PikSend in a supported browser (Chrome, Edge, Safari)
2. Look for the "Install" prompt in the address bar
3. Click "Install" to add PikSend to your home screen

#### Enabling Push Notifications

1. Go to Settings in your dashboard
2. Find "Push Notifications" section
3. Toggle "Enable notifications"
4. Grant permission when prompted by the browser

### For Developers

#### Subscribing to Push Notifications

```typescript
import { usePushNotifications } from '@/hooks/use-push-notifications';

function MyComponent() {
  const { subscribe, isSubscribed } = usePushNotifications();

  const handleSubscribe = async () => {
    const subscription = await subscribe();
    if (subscription) {
      // Save to backend
      await fetch('/api/push/subscribe', {
        method: 'POST',
        body: JSON.stringify(subscription),
      });
    }
  };

  return (
    <button onClick={handleSubscribe}>
      {isSubscribed ? 'Subscribed' : 'Subscribe'}
    </button>
  );
}
```

#### Sending Push Notifications

```typescript
import { createNotificationDispatcherService } from '@/lib/services/notification-dispatcher.service';
import { createClient } from '@/lib/supabase/server';

// In your API route or server action
const supabase = await createClient();
const notificationService = createNotificationDispatcherService(supabase);

// Notify about new comment
await notificationService.notifyNewComment(imageId, galleryTitle);

// Notify about new favorite
await notificationService.notifyNewFavorite(galleryId, galleryTitle, favoriteCount);

// Notify about expiration
await notificationService.notifyGalleryExpiration(galleryId, galleryTitle, daysRemaining);
```

## Testing

### Testing PWA Installation

1. Build the production version: `npm run build`
2. Start the production server: `npm start`
3. Open in Chrome DevTools > Application > Manifest
4. Verify all manifest fields are correct
5. Click "Add to home screen" to test installation

### Testing Push Notifications

1. Subscribe to notifications in the app
2. Use the browser's DevTools to send a test notification:
   - Chrome: DevTools > Application > Service Workers > Push
3. Or use the web-push CLI:

```bash
npx web-push send-notification \
  --endpoint="<subscription-endpoint>" \
  --key="<p256dh-key>" \
  --auth="<auth-secret>" \
  --vapid-subject="mailto:contact@piksend.com" \
  --vapid-pubkey="<your-public-key>" \
  --vapid-pvtkey="<your-private-key>" \
  --payload='{"title":"Test","body":"Test notification"}'
```

### Testing Offline Support

1. Open DevTools > Network
2. Select "Offline" from the throttling dropdown
3. Navigate to a previously visited gallery
4. Verify images load from cache

## Troubleshooting

### PWA Not Installing

- Ensure you're using HTTPS (required for PWA)
- Check that manifest.json is accessible at `/manifest.json`
- Verify all required manifest fields are present
- Check browser console for errors

### Push Notifications Not Working

- Verify VAPID keys are correctly set in environment variables
- Check that the user has granted notification permission
- Ensure the service worker is registered and active
- Check browser console for push subscription errors
- Verify the push_subscriptions table exists in the database

### Service Worker Not Updating

- Hard refresh the page (Ctrl+Shift+R or Cmd+Shift+R)
- Unregister the service worker in DevTools > Application > Service Workers
- Clear site data and reload
- Ensure `skipWaiting: true` is set in next.config.ts
