## 🆓 Plan FREE

### Objectif
**Vitrine de qualité** - Permettre aux photographes de tester PikSend avec une vraie galerie HD pour créer le "Wow effect" et les inciter à upgrader.

### Limites de stockage
- **Stockage** : 500 MB
- **Galeries** : 2 maximum
- **Images par galerie** : 50 maximum
- **Taille max par image** : 25 MB (HD autorisé)
- **Expiration** : 7 jours maximum

### Fonctionnalités incluses

#### ✅ Galerie & Affichage
- **Grille Masonry responsive** : Affichage adaptatif 2-5 colonnes
- **Lightbox plein écran** : Visionneuse avec navigation clavier/swipe
- **Mode sombre/clair** : Détection automatique + toggle manuel
- **Lazy loading** : Chargement progressif optimisé

#### ✅ Upload & Gestion
- **Upload drag & drop** : Interface intuitive
- **Upload de dossiers** : Glisser un dossier complet
- **Gestion des galeries** : Créer, renommer, supprimer
- **Tri intelligent** : Par nom, date, taille, manuel
- **Expiration 7 jours** : Urgence pour inciter à l'upgrade
- **Protection mot de passe** : Sécurité basique

#### ✅ Performance
- **Zero compression** : Qualité originale préservée
- **CDN Cloudinary** : Livraison rapide mondiale
- **SEO Opt-Out** : Galeries privées non indexées
- **Multi-langues** : FR/EN minimum

#### ✅ Outils
- **QR Code Generator** : Pour partage événementiel
- **PWA** : Installation comme app mobile
- **Statistiques basiques** : Nombre de vues

#### ⚠️ Limitations
- **Watermark PikSend** : Logo PikSend sur les images
- **Pas de ZIP** : Téléchargement individuel uniquement
- **Pas de Slideshow** : Mode diaporama désactivé
- **Pas de Favoris** : Système de sélection désactivé
- **Pas de Commentaires** : Feedback client désactivé
- **Expiration courte** : 7 jours max (crée l'urgence)

### 💡 Cas d'usage
- Photographes débutants testant la plateforme
- Petits événements ponctuels
- Partage rapide avec quelques clients
- Découverte de PikSend avant upgrade

## 💎 Plan PREMIUM

### Objectif
**Efficacité professionnelle** - Débloquer les outils essentiels pour un workflow pro : ZIP, Favoris, Commentaires, Slideshow.

### Prix
- **Mensuel** : 9.99 €/mois
- **Annuel** : 95.90 €/an (~20% de réduction)

### Limites de stockage
- **Stockage** : 100 GB
- **Galeries** : 100 maximum
- **Images par galerie** : 500 maximum
- **Taille max par image** : 100 MB
- **Expiration** : 90 jours maximum

### Fonctionnalités incluses

#### ✅ Tout du plan Free, PLUS :

#### 🎬 Expérience galerie améliorée
- **Slideshow** : Mode diaporama automatique avec contrôles
- **Favoris** : Clients peuvent marquer leurs photos préférées
- **Commentaires** : Feedback direct sur chaque image
- **Deadline Timer** : Compte à rebours pour sélection

#### 📦 Téléchargement avancé
- **ZIP Bulk Download** : Télécharger toutes les photos en un clic
- **Téléchargement sélection** : ZIP des photos sélectionnées
- **Téléchargement favoris** : ZIP des photos favorites

#### 🎨 Personnalisation
- **Watermark personnalisé** : Votre logo au lieu de PikSend
- **Testimonial Collector** : Collecte d'avis clients

#### 🤖 IA
- **Auto-Captioning** : Descriptions automatiques par IA

#### 📊 Stockage & Limites
- **100 GB** : Suffisant pour un photographe actif
- **100 galeries** : Gérer plusieurs clients simultanément
- **500 images/galerie** : Mariages, événements complets
- **90 jours d'expiration** : Flexibilité pour projets longs

### 💡 Cas d'usage
- Photographes professionnels actifs
- Mariages, événements, portraits
- Besoin de workflow efficace
- Interaction client importante

## 🚀 Plan PRO

### Objectif
**Prestige & White-Label** - Solution complète pour studios professionnels avec branding personnalisé, domaine custom, et toutes les fonctionnalités avancées.

### Prix
- **Mensuel** : 19.99 €/mois
- **Annuel** : 191.90 €/an (~20% de réduction)

### Limites de stockage
- **Stockage** : 1 TB (1000 GB)
- **Galeries** : Illimité (9999)
- **Images par galerie** : 2000 maximum
- **Taille max par image** : 500 MB (RAW/TIFF supportés)
- **Expiration** : 365 jours maximum

### Fonctionnalités incluses

#### ✅ Tout du plan Premium, PLUS :

#### 🎨 White-Label Branding
- **Logo personnalisé** : Votre logo partout (header, lightbox, slideshow, footer)
- **Domaine personnalisé** : photos.votredomaine.com
- **Couleurs de marque** : Personnalisation complète de l'interface
- **Page de profil pro** : Vitrine publique de vos galeries
- **Footer personnalisé** : Aucune mention PikSend

#### 💰 Monétisation
- **Paywall** : Vendre l'accès aux galeries via Stripe
- **Lead Magnet** : Capture d'emails avant accès
- **Bouton CTA** : Call-to-action personnalisable

#### 📊 Analytics avancées
- **Statistiques détaillées** : Pays, dates, comportement
- **Tracking conversions** : Suivi des ventes et leads

#### 🎥 Médias enrichis
- **Video Cover** : Vidéo de fond immersive
- **Audio Gallery** : Musique d'ambiance

#### 🔌 Intégrations
- **Adobe Lightroom Plugin** : Export direct depuis Lightroom
- **Face Recognition** : Tri automatique par visage
- **Smart Culling** : IA détecte flou, yeux fermés, doublons

#### 📦 Stockage massif
- **1 TB** : Pour studios avec gros volumes
- **Galeries illimitées** : Aucune restriction
- **2000 images/galerie** : Événements de grande envergure
- **365 jours d'expiration** : Archivage long terme

### 💡 Cas d'usage
- Studios professionnels établis
- Photographes avec forte identité de marque
- Besoin de white-label complet
- Monétisation des galeries
- Gros volumes de photos
- Intégration workflow avancé
