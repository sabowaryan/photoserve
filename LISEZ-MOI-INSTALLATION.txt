🚀 DÉMARRAGE RAPIDE
═══════════════════

1. Ouvrez un NOUVEAU PowerShell (pour charger le PATH mis à jour)

2. Testez l'installation :
   
   cd PikSend.lrplugin
   run-tests.bat tests\test_auth_token_storage.lua

3. Résultat attendu : "Passed: 19, Failed: 0, Total: 19 ✓ All tests passed!"

═══════════════════

Lancer tous les tests :

  run-tests.bat

Lancer un test spécifique :
  cd PikSend.lrplugin
  run-tests.bat tests\test_auth_token_storage.lua

Vérifier les versions :
  lua -v
  gcc --version
  luarocks --version
  busted --version
