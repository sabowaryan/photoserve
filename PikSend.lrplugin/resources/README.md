# Resources Directory

This directory contains visual resources for the PikSend Lightroom plugin.

## Required Files

- **icon.png** - Plugin icon (displayed in Lightroom's Plugin Manager)
  - Recommended size: 256x256 pixels
  - Format: PNG with transparency

- **logo.png** - PikSend logo (displayed in dialogs and settings)
  - Recommended size: 200x50 pixels
  - Format: PNG with transparency

- **watermark-default.png** - Default watermark image
  - Recommended size: 200x200 pixels
  - Format: PNG with transparency

## Notes

These files should be added before packaging the plugin for distribution.
For development purposes, placeholder files can be used.
