## Screenshot Guidelines

### General Requirements

- **Format**: PNG (for transparency and quality)
- **Quality**: High resolution, clear text
- **Privacy**: Blur or redact any personal information:
  - User names (except in demo contexts)
  - Email addresses
  - API tokens
  - Photo thumbnails (if sensitive)

### Annotation Guidelines

- Use red rectangles or arrows to highlight important UI elements
- Add numbered callouts if multiple steps are shown
- Keep annotations minimal and clear
- Use consistent styling across all screenshots

### File Naming

- Use lowercase with hyphens
- Be descriptive but concise
- Match the names referenced in the installation guides

### Platform-Specific Notes

#### Windows
- Use Windows 10 or 11 with default theme
- Capture at 100% or 125% scaling (not 150%+)
- Include window title bars

#### macOS
- Use macOS 11 (Big Sur) or later
- Capture at 2x resolution (Retina)
- Include window title bars and traffic lights

## Creating Screenshots

### Tools

**Windows**:
- Snipping Tool (Windows 10)
- Snip & Sketch (Windows 11)
- ShareX (for annotations)

**macOS**:
- Cmd + Shift + 4 (area selection)
- Cmd + Shift + 5 (screenshot toolbar)
- Preview (for annotations)

### Workflow

1. Set up Lightroom in a clean state
2. Use demo photos (not client work)
3. Capture the screenshot
4. Annotate if needed
5. Save as PNG
6. Verify clarity and readability
7. Place in this directory
